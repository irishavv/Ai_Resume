## ⚠️ Timing Kaise Kaam Karti Hai (ye 1 minute padh lo)

Meri pehli script mein galti thi: maine "Narration 23s" aur "Screen 20s" alag-alag likh diya. Isse laga ki 23 second ka slot hai aur screen kaam 20 second ka — to bache 3 second kahan gaye?

**Asli baat ye hai:**

> Aap **bolte waqt hi** screen par kaam bhi kar rahe ho. Dono ek saath chalte hain.
> Screen ka "20 second" wala hissa us waqt **khatam nahi hota** — uske baad screen **usi jagah par ruki rehti hai** jab tak aap bol rahe ho.

Isliye ab maine **har section mein ek timeline table** di hai. Us table mein:

- **Pehla column** = section ke andar ka time (0 second se shuru)
- **Doosra column** = us waqt screen par **kya dikh raha hai**
- **Teesra column** = us waqt aap **konsi line bol rahe ho**

**Table ki saari rows ka jod (sum) = poora section.** Ek second bhi khaali nahi chhoda.

> **Poora hisaab dekhna hai?** Neeche **MASTER TIMELINE** ke baad ek **"TIMING AUDIT"** table hai — usme har section ka slot, uske screen-kaam ka jod, aur narration — teeno aamne-saamne likhe hain.

### Do zaroori baatein

1. **Voice-over alag se record karo.** Pehle poori screen record karo (bina bolne ke bhi chalega), phir aaram se baith kar mic par narration record karo. Yahi sabse aasan tareeka hai — dono cheezein ek saath karne ki koshish mat karo.
2. **Har section ko alag take mein record karo.** Section khatam → recording band → agli section. Isse editing bahut aasan ho jayegi.

### 🎥 Recording Order — bilkul isi order mein kaam karo

| Step | Kya karo | Kyun |
| --- | --- | --- |
| **1** | `run-all.bat` chalao, teen services start karo, aur `.env` check karo (**camera par mat kholo**) | Aage ka sab kaam isi par depend karta hai |
| **2** | **Pehle Section 6, 7, 8, 9** ki screen recording karo | Inme sabse zyada screen kaam hai, aur **Section 3 ka roadmap bhi inhi clips se banega** |
| **3** | Phir **Section 1, 2, 4, 5, 10, 11** ki screen recording karo | Har section alag take — recording band, agli section |
| **4** | Ab **narration (voice-over)** record karo — Section 1 se 11 tak, ek-ek line (L1, L2, L3…) aaram se bolo | Screen pehle se ready hai, isliye sirf apni awaaz par dhyaan do |
| **5** | CapCut/Clipchamp mein narration ko clip ke saath align karo, phir **Post-Production Checklist** follow karo | Bas itna hi kaam bacha |

> **Screen aur voice ka match kaise pata chalega?** Har section ki timeline table ka **teesra column** batata hai ki us waqt **konsi line** chalni chahiye. Live recording mein aapko bologe nahi — bas section ka poora kaam **uske slot jitna lamba** record karo. Baad mein voice-over mein line usi hisse par rakhni hai.

## 🧑‍💻 Beginner Editing Guide (CapCut ya Clipchamp)

Ye 7 kaam aapko karne honge. Bas itna hi. (Menu ke naam app ke hisaab se thode alag ho sakte hain.)

| Kaam | Kaise karo |
| --- | --- |
| **1. Kaise ek hissa kaato (Trim)** | Clip ko timeline mein select karo → jahan se kaatna hai wahan playhead lao → **`Ctrl+B`** (Split) → jo hissa hatana hai usko select karke **`Delete`** |
| **2. Kaise video ko 2x speed karo** | Clip select → right side panel → **`Speed`** → **`2x`** |
| **3. Kaise zoom karo (dheere dheere bada)** | Clip select → **`Zoom`** / **`Scale`** → clip ke **start** par keyframe lagao (100%) → clip ke **end** par 110% set karo → app khud smooth zoom bana dega |
| **4. Kaise text add karo** | Upar **`Text`** → `+ Add text` → type karo → screen par drag karke corner mein rakh do |
| **5. Kaise laal circle banao** | **`Stickers`** ya **`Shapes`** → circle chuno → colour **red** karo → `Border/Outline` on karo → jis cheez par point karna hai wahan resize karke rakh do |
| **6. Kaise email/phone blur karo** | **`Effects`** → **`Blur`** → usko timeline par us jagah drag karo → size badha kar email/phone ke upar rakh do |
| **7. Kaise fade out karo** | Last clip ke end par → **`Transitions`** → **`Fade`** → drag karke laga do |

> **Jargon ki chhoti dictionary:**
> - **Lower third** = screen ke niche-left corner mein aane wali chhoti patti (naam/branding ke liye)
> - **Zoom punch** = us area ko thoda bada karke dikhana (105–115%)
> - **Callout** = laal circle/teer banakar kisi cheez par dhyan khenchna
> - **B-roll** = baat karne ke waqt dikhne wala extra footage
> - **Cut** = video ka bekaar hissa kaat dena
